ForRocket Workbench

ロケット弾道計算ツール ForRocket のブラウザベース GUI。プロジェクト管理・計算実行・結果確認・設定編集をひとつのインターフェースで行えます。

1 概要

ForRocket Workbench はローカルで動作する Web アプリです。ブラウザを使って ForRocket ソルバーを操作します。計算履歴の管理や結果グラフの閲覧に加え、全設定ファイルをフォーム UI で編集できます。

📊

計算履歴管理

全ての計算実行を SQLite DB に記録。日時・モード・ステータスで一覧表示します。

⚙️

4 つの計算モード

Trajectory・Area・MonteCarlo・Sensitivity の各計算をワンクリックで実行できます。

✏️

全ファイルのフォーム編集

全 8 設定ファイルをフォーム UI で編集できます。JSON 直接編集モードも提供します。

🖼️

インタラクティブ結果表示

PNG グラフ・ECharts チャート・Leaflet マップで計算結果を詳細に確認できます。

ℹ️

アプリは python main.py で起動し、http://localhost:8080 でアクセスします。

計算はバックグラウンドスレッドで実行されるため、実行中もブラウザ操作は継続できます。

左ペイン — 計算実行

  1. プロジェクトを選択。ドロップダウンに projects/ フォルダ内のプロジェクトが表示されます。
  2. 計算モードを選択。ラジオボタンで 4 種類のモードから選びます。
  3. 必要に応じて 「Use max CPU threads」にチェックを入れます（Area / MonteCarlo / Sensitivity で有効）。
  4. Project Files で必要ファイルを確認。✓ が全て揃っていれば実行可能です。
  5. 「Run Calculation」を押す。進捗バーとステップラベルが更新されます。
  6. 完了後、「View Results」ボタンが自動表示されます。クリックすると Result ページへ移動します。

進捗ステップ

Stepラベル内容
1 / 4Preparing files...実行準備・パス解決
2 / 4Running solver...runner_tool によるソルバー実行
3 / 4Post processing...post_tool によるグラフ生成・CSV 出力
4 / 4Saving results...DB への結果保存

キャンセル

実行中に表示される「Cancel」ボタンを押すと、実行中のサブプロセスを終了させます。ステータスは cancelling → cancelled に遷移します。

右ペイン — 設定ファイルフォームエディタ

プロジェクト内の設定ファイルをドロップダウンで選択すると、Form タブと JSON タブが表示されます。全 8 ファイルにフォーム UI が用意されています。

ファイルフォームの主要項目
config_solver.json Model ID・Launch DateTime・打上げ条件（緯度/経度/高度/方位角/仰角）・Wind（Enable/ファイルパス）・初速・初期角速度
param_list_stage1.json ステージ数・各ステージのパラメータファイルパス
param_rocket.json 機体外形・質量・各空力係数（定数値 or ファイル指定トグル）・CG/CP 位置
param_engine.json ノズル径・推力（定数 or ファイル）・質量流量・燃焼時間・エンジン軸ずれ
sequence_of_event.json 各イベント（点火・レール離脱・段分離・パラシュート展開等）の Enable + 時刻
config_area.json Law Wind 係数・基準高度、風速範囲（Lo/Hi/Step）、風向範囲（Lo/Hi/Step）。入力変更のたびにケース数をリアルタイム表示。
config_montecarlo.json Case Count、22 種類の誤差パラメータ（Enable・Unit・3σLow・3σHigh）。Wind のみ zip ファイルパス入力。
config_sensitivity.json 計算手法（two_point / linear_fit）、感度パラメータ一覧（パラメータ名・Variation Unit・Variations リスト・Reference Variations リスト）。行の追加・削除可能。

「JSON」タブに切り替えると生の JSON テキストを確認・直接編集できます。「Save」でフォームの値を JSON として projects/<name>/ に保存、「Reformat」で JSON を再フォーマット（保存なし）。

ℹ️

JSON の構文エラーがある状態で Save を押すと、エラーメッセージがトースト通知で表示されます。保存は実行されません。

プロジェクト作成

「+ New Project」ボタンを押すとダイアログが開きます。プロジェクト名を入力して「Create」を押すと projects/<name>/ ディレクトリが作成されます。

⚠️

プロジェクト作成後、設定ファイルは手動でフォルダに配置してください。フォームエディタはファイルの新規作成はせず、既存ファイルの編集のみ行います。

同時に実行できる計算は 1 つだけです。既に計算が実行中の場合、Run ボタンを押すと警告が表示されます。

5 Result（結果表示）

GET http://localhost:8080/result/{calc_id}

個別の計算結果を表示するページです。メタデータの確認・メモの記録・出力グラフの閲覧・結果フォルダのオープンができます。

共通セクション

セクション内容
メタデータカードMode・Project・Model ID・Status・Started・Finished の 6 項目
Memoテキストエリアに記入し「Save Memo」で DB に保存。Dashboard の一覧にも反映。
Result Directory結果フォルダのパスと「Open Folder」ボタン（Windows エクスプローラーで開く）

Trajectory 結果

  • Output Graphs: 結果フォルダ内の PNG ファイルを 2 列グリッドでブラウザ内表示
  • Leaflet マップ: 飛翔経路（緯度・経度ポリライン）・発射点マーカー・落下点マーカー

Area 結果

  • Output Graphs: PNG ファイルを 2 列グリッドで表示
  • Leaflet マップ: 落下エリアエンベロープポリゴン・個別落下点散布・発射点マーカー

MonteCarlo 結果

  • 統計値カード: 頂点高度・落下点 East・落下点 North のそれぞれについて mean / std / 3σ を表示
  • ECharts ヒストグラム: 頂点高度・落下点 East・落下点 North の度数分布チャート
  • ECharts 散布図: 落下点 East-North 散布図（3σ 楕円オーバーレイ付き）
  • Leaflet マップ: 全ケース落下点散布・3σ 楕円ポリゴン・発射点マーカー

Sensitivity 結果

  • サマリテーブル: sensitivity_results.csv の内容（パラメータ・基準値・感度係数 [m/unit] / [m/%]・変化幅）
  • Tornado チャート: sensitivity_tornado.png をブラウザ内表示
  • Linearity Check（開閉式パネル）: パラメータごとに ECharts 散布図で線形性を確認
    • 青丸 ●: Reference Variations 以外の全 Variations 解析点
    • 橙菱形 ◆: Reference Variations の点（感度係数算出に使用した基準点）
    • 緑三角 ▲: ノミナル値の点
    • 破線 —: Reference Low 点を基準とした感度係数による線形近似線

    X 軸はパラメータの実際の値（ノミナルを中心に対称スケール）、Y 軸は頂点高度（ノミナルを中心に対称スケール）で表示されます。傾きが実際の解析点に合っているかを視覚的に確認できます。

💡

Linearity Check で解析点が破線上に乗っていない場合、感度計算で使用したメソッド（two_point / linear_fit）と実際の非線形性の程度を確認してください。

6 計算モード一覧

モード バッジ色 概要 追加設定ファイル
trajectory 青 単一条件での弾道計算。最も基本的なモード。 なし
area 緑 複数の打上げ条件（風速・風向の組み合わせ）での着弾点エリア計算。 config_area.json
montecarlo 紫 パラメータにばらつきを与えたモンテカルロシミュレーション。 config_montecarlo.json
sensitivity 橙 各パラメータが頂点高度に与える感度分析（OAT 法）。 config_sensitivity.json
ℹ️

Area・MonteCarlo・Sensitivity モードでは「Use max CPU threads」チェックボックスが有効です。並列計算でコア数をフル活用します。

7 設定ファイル一覧

全ファイルはプロジェクトフォルダ（projects/<project_name>/）に配置します。

ファイル名 必須モード 説明
config_solver.json 全モード ソルバー基本設定（モデル ID・打上げ条件・風条件など）。フォーム UI で編集可。
param_rocket.json 全モード ロケット機体パラメータ（外形・質量・空力係数）。フォーム UI で編集可。
param_engine.json 全モード エンジンパラメータ（推力・質量流量・燃焼時間）。フォーム UI で編集可。
param_list_stage1.json 全モード ステージ 1 のパラメータファイルリスト。フォーム UI で編集可。
sequence_of_event.json 全モード イベントシーケンス定義（点火・分離・パラシュート等）。フォーム UI で編集可。
config_area.json Area のみ エリア計算の風条件設定（範囲・刻み）。フォーム UI で編集可。
config_montecarlo.json MonteCarlo のみ モンテカルロのケース数と各パラメータのばらつき設定（22 項目）。フォーム UI で編集可。
config_sensitivity.json Sensitivity のみ 感度分析の計算手法・対象パラメータと変化量。フォーム UI で編集可。

Calculate ページの「Project Files」パネルで各ファイルの存在確認ができます。

✓ ファイルが存在する
✗ 必須ファイルが存在しない（計算不可）
– オプションファイルが存在しない（そのモードでは不要）

13 FAQ

Q. アプリが起動しない

Python の依存ライブラリが不足している可能性があります。pip install nicegui fastapi sqlalchemy pandas numpy でインストールしてください。

Q. ブラウザが自動で開かない

http://localhost:8080 を手動で開いてください。

Q. Run ボタンを押したが計算が始まらない

以下を確認してください：(1) 必要な設定ファイルがすべて存在するか（Project Files パネルで✗がないか）。(2) 別の計算が実行中でないか（同時実行は 1 つのみ）。(3) ForRocket バイナリが ForRocketWorkbench/ 直下に存在するか。

Q. 計算は完了したが Result ページにグラフが表示されない

post_tool による後処理が正常に完了しているか確認してください。Result Directory の「Open Folder」ボタンで結果フォルダを開き、PNG ファイルが生成されているか確認できます。

Q. フォームエディタで保存した内容が反映されない

Save ボタンを押した後にトースト通知（画面右上）でエラーが表示されていないか確認してください。JSON 構文エラーがある場合は保存されません。

Q. Linearity Check で破線が解析点からズレている

これは感度係数算出に使用した Reference Variations 点（橙菱形）の傾きで引いた直線です。他の Variations 点（青丸）が直線上にない場合、そのパラメータの感度は非線形性を持ちます。計算手法を linear_fit に変更するとより多点でフィットした感度係数が得られます。

Q. Editor ページの URL を使っているがアクセスできない

/editor は現在 /calculate へリダイレクトされます。設定編集機能は Calculate ページの右ペインに統合されています。
